# Experiment 9: Password Hashing With and Without Salting

## 1. Objective
To implement password hashing with and without salting in Java, and evaluate resistance against rainbow table and brute-force attacks.

## 2. Software Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code)

## 3. Source File
- `PasswordHashing.java`

## 4. Conclusion
Adding a unique cryptographic salt before hashing ensures identical passwords produce different hashes, defending against precomputed rainbow table attacks.

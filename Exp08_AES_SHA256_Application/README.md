# Experiment 8: Text Message Security using AES and SHA-256

## 1. Objective
To develop a Java application to secure text messages using AES encryption and SHA-256 hashing in VS Code.

## 2. Software Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code)

## 3. Source File
- `AESHash.java`

## 4. Conclusion
Combining AES symmetric encryption with SHA-256 hashing ensures both message confidentiality and tamper detection.

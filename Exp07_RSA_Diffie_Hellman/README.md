# Experiment 7: RSA and Diffie-Hellman Key Exchange in Java

## 1. Objective
To implement RSA and Diffie-Hellman algorithms in Java to demonstrate secure key exchange and public-key cryptography using VS Code.

## 2. Software Required
- Java Development Kit (JDK)
- Visual Studio Code (VS Code)

## 3. Source Files
- `RSA.java`
- `DiffieHellman.java`

## 4. Conclusion
Diffie-Hellman enables two parties to establish a shared secret key over an insecure channel, while RSA provides asymmetric encryption and key exchange.
